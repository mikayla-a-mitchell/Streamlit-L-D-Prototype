# Mathematics Learning Design Prototypes

**Live app:** [app-l-d-prototype.streamlit.app](https://app-l-d-prototype.streamlit.app/)

This repository hosts the Streamlit app that presents two interactive Grade 6
mathematics learning-design prototypes by Mikayla Mitchell. Both explore
expression writing, grouping, the distributive property, and equivalence
(CCSS 6.EE.A.2–4).

| Prototype | Approach | Source, design brief, and playtest guide |
|---|---|---|
| **Split Decision** | Familiar context: how splitting an online order changes the total | [Split-Decision](https://github.com/mikayla-a-mitchell/Split-Decision) |
| **Assembly X** | Abstract expression factory: build a rule, run it, revise it | [Assembly-X-Factory](https://github.com/mikayla-a-mitchell/Assembly-X-Factory) |

The app code lives in [`streamlit-prototypes-fixed/`](streamlit-prototypes-fixed/),
with instructions for running it locally.
